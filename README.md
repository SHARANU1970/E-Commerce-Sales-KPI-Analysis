# E-Commerce Sales & KPI Performance Analysis

## Project Summary
Analyzed 10,000+ e-commerce order records across 5 categories using SQL and Excel, with Power BI dashboard design for KPI and category-level reporting.

## Resume-aligned work
- Analyzed 10,000+ order records across 5 categories.
- Used SQL and Excel techniques including pivot-style summaries, SUMIFS/VLOOKUP-style analysis, grouping and segmentation.
- Built a systematic data-cleaning workflow for missing values and duplicate orders.
- Tracked revenue, profit, units sold, average order value (AOV), and category contribution.
- Designed Power BI dashboard pages for stakeholder review.

## Data-quality note
The included dataset is a **generated portfolio/demo dataset**, created to demonstrate cleaning, duplicate handling and KPI analysis. The project documents a portfolio data-quality score of approximately **68% before cleaning and 96% after cleaning**; these figures are demo-project metrics, not an independently audited business data-quality measurement.

## Power BI note
The PNGs are **dashboard design previews**, not screenshots exported from Power BI Desktop. A genuine `.pbix` file must be created and saved in Power BI Desktop.
